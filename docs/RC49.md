# RC49：走跑动画与原生交互 / Movement animation and native interaction

2026-10-26 · `20261026-player-rc49`

- 修复可复现的静帧平移：耐力耗尽后，适配层反复请求跑步、核心切回走路，导致动画不断从开头重置。现在请求跑步前查询原生耐力，耗尽时使用走路请求。
- L3（左摇杆下压）切换走路/跑步；耐力不足时保留原生走路规则。
- 世界页面 X 使用原生目标交互，可与附近 NPC、地面物品、交互物和副本入口交互。移除旧的跨窗口鼠标点击，解决 NPC 交互时的闪退。
- 中文补丁继续内置主适配包。

- Fixes reproduced sliding with a frozen pose: after stamina reaches zero, repeated forced-run requests fought the engine's walk fallback and restarted the animation. Run requests now check native stamina and use walk when exhausted.
- L3 toggles walk/run, subject to native stamina eligibility.
- In the world, X uses native target interaction for nearby NPCs, ground items, objects and dungeon entrances. Removing the old cross-window mouse-click path fixes its NPC-interaction crash.
- The Chinese patch remains integrated in the main adapter package.

## 验证 / Validation

74 项本地测试、原字节恢复基准审计和全新玩家导入通过。新包 239 项；导入校验固定核心、12 个正版资源及 12 张前端位图；缺失/错误核心和重复导入会被拒绝。

独立玩家副本实测通过 NPC 对话、L3 走跑及 X 从鲜血荒地进入邪恶洞窟。捕捉到原生受击恢复后，走跑动画正常。耐力耗尽对照中，修复前动画反复停留在前两个离散帧；修复后零耐力下的 608 个走路样本覆盖完整八帧，移动继续。用户肉眼确认目前基本无问题并授权发布。正式玩家存档、prefix 和核心保持原字节。

74 local tests, the recovered-byte audit and a fresh-player import passed. The 239-file package verifies the pinned core, 12 retail resources and 12 frontend bitmaps; missing/invalid cores and repeat imports are rejected. Independent device tests confirmed NPC dialogue, L3 walk/run, and X entering the Den of Evil from the Blood Moor. Movement animation remained normal after a captured native hit recovery. With stamina exhausted, the old animation repeatedly reset to its first two discrete frames; the fix covered all eight frames across 608 walking samples while movement continued. The user visually confirmed normal behavior and authorized publication. Formal saves, prefix and core remained byte-identical.

这些是本轮操作和可复现故障的验证，不代表全部职业、技能或长期战斗已穷尽测试。系统触摸噪声仍属独立问题。

This validates the tested actions and reproduced fault, rather than exhaustive classes, skills or long-term combat. System touch noise remains a separate issue.

## 原生补丁边界 / Native patch boundary

固定 1.13d 核心未改。`world_probe.so` 的完整精确源码仍未恢复；本次仅对固定哈希的恢复适配库增加可复现补丁：扩大交互目标循环以纳入 type 5 入口，并在已有 RX 对齐空隙加入 56 字节 ARM 耐力判断。仅扩展原 RX 段长度，不增加可写可执行段。

The pinned 1.13d core is unchanged. The exact complete `world_probe.so` source is still unavailable. This release applies reproducible patches to the hash-pinned recovered adapter: include type-5 entrance targets and add a 56-byte ARM stamina check in verified unused RX alignment padding. Only the existing RX segment length is extended; no writable executable segment is added.
